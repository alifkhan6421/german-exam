# Exam blueprints: verification status

Generated by `npx tsx scripts/blueprint-report.ts` on 2026-10-11 from `src/domain/blueprints`.

Every factual claim about an official exam (sections, parts, item counts, timings, points, pass rules,
playback counts) is stored as a `Fact` with status **verified** (with source and reference) or **unverified**
(with the reason). Sources are listed in `src/domain/blueprints/facts.ts`.

What unverified facts do in the app:

- An exam built on a blueprint with unverified facts **cannot be published** until a Content Admin or Super
  Admin confirms that blueprint version in **Admin → Blueprints**. Confirming means checking the facts against the
  official handbook or Modellsatz and recording a note. It is audit-logged.
- Pass estimates are shown only when the pass rule and section maxima are verified or confirmed. Otherwise the
  result page shows points without a pass/fail estimate and explains why.
- If an administrator finds a fact is wrong, fix it in `src/domain/blueprints/*.ts`, bump the blueprint `version`,
  and redeploy. Existing exam versions keep the blueprint version they were built on.
